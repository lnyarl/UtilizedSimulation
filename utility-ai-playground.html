기대효용 비교

막대 = P×D. 무기1이 명중률 높아도 무기2가 이기는 구간을 만들어보세요.
이 모듈이 보여주는 개념

게임월드는 비결정적입니다. "공격하면 맞을 수도, 빗나갈 수도". 그래서 기대효용을 씁니다:

EU = Σ Pᵢ × Dᵢ (P=확률, D=바람직함)

원문 RPG 예시: 무기1 (85% × 0.6 = 0.51) vs 무기2 (60% × 0.9 = 0.54) → 무기2 선택.

명중률이 낮아도, 맞으면 치명적인 쪽이 기대효용으로 이길 수 있습니다. 이것이 "리스크 감수형" AI와 "안전 추구형" AI를 가르는 지점입니다.

이 모듈이 보여주는 개념

현실의 결정은 요소가 하나가 아닙니다. 체력·배고픔·적 거리·피로가 동시에 작용합니다.

각 요소의 효용을 따로 구하고 가중치로 합칩니다:

최종효용 = w₁×(요소1) + w₂×(요소2) + ...

가중치를 바꾸면 같은 상황에서 다른 행동을 고릅니다. 이게 NPC「성격」입니다.
- 공격성 높음 → 적이 가까우면 거의 항상 공격
- 생존본능 높음 → 체력 낮으면 무조건 도망
- 탐욕 높음 → 배고프면 전투 중이어도 먹기

틱별 결정 타임라인

위=공격, 아래=도망. 색이 자주 바뀌면 진동(oscillation)입니다.
이 모듈이 보여주는 개념

AI가 매 프레임 결정하고, 두 행동의 효용이 0.50 vs 0.49처럼 비슷하면?

→ 공격-도망-공격-도망으로 떠는 최악의 AI가 됩니다. (oscillation)

해결책:

1) 현재 행동에 보너스 → 비슷하면 계속 유지, 확 높은 새 행동이 올 때만 전환
2) 행동 커밋 → 액션 완료 전에는 재의사결정 금지 ("공격 모션 끝나기 전엔 딴 생각 안 함")

결정 로그

이 모듈이 보여주는 개념

앞의 5개 모듈이 전부 들어간 종합 예제입니다.

- 반응 커브: 니드(0~100) → 효용 변환
- 다요소 합산: 여러 니드 + 오브젝트 회복량 → 행동 효용
- 선택 전략: Argmax (지금은 단순 최고점)
- 관성: 같은 오브젝트 사용 중이면 유지
- 기대효용 개념: 오브젝트의 회복 효과가 행동의 "D"

프리셋은 가중치 세트입니다. 먹보=식욕 가중치↑, 게으름뱅이=휴식↑. 같은 월드, 같은 규칙인데 성격만으로 행동이 완전히 달라집니다.
