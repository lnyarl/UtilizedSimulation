① 시뮬 = 로그 객체 생성. 서버에서 돌린다는 건 말장난이고, 실제로는 90분(54,000틱)을 루프로 즉시 소화해 구조화된 로그 객체를 남깁니다.

로그 객체 구조

{
  meta: { seed, tickDt, field, ... },
  frames: [ [t, ballX, ballY, owner, [[x,y]×10]], ... ],  // 0.2초 간격
  events: [ { t, type: "goal"|"shot"|"pass"|"tackle", ... }, ... ],
  score: [home, away],
  stats: { possession, shots, passes, tackles, goals }
}

② 뷰어 = 플레이백 전용. 로그를 해석해 캔버스에 그릴 뿐, AI/물리를 다시 돌리지 않습니다. 시크·배속·이벤트 점프 모두 프레임 배열 인덱스를 참조합니다.

선수 AI는 Utility 기반입니다. 볼 소유자는 슛/패스/드리블/홀드를 효용 점수로 비교하고, 오프볼 선수는 압박·마킹·서포트를 상황 효용으로 고릅니다. 공격성 슬라이더는 그 성격 가중치입니다.
